Fonts used to render the 1200x630 Open Graph cards (scripts/og-cards.js).
Text is converted to vector paths with opentype.js, so the build does not
depend on fonts installed on the CI runner or the VPS.

- DM Serif Display (Colophon Foundry): SIL Open Font License 1.1
- Lato (Łukasz Dziedzic): SIL Open Font License 1.1
- Cormorant SC (Christian Thalmann): SIL Open Font License 1.1
